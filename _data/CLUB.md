1. 技术栈：
    - SpringBoot + MyBatis-Plus + Redis + Nginx + RabbitMq + MySql + Ruoyi
2. 主要职能：
    - 基于若依框架的RBAC模型，设计**四级权限控制**模块（菜单权限、操作权限、数据权限、部门权限），通过@DataScope注解实现数据过滤，确保管理人员仅能查看本部门数据。
    - 开发活动发布-审核-执行闭环流程，利用**RabbitMQ延迟队列**实现活动自动生效/终止，结合Redis缓存活动状态，审核响应时间缩短至300ms以内。
    - 采用**Redis Hash+分布式锁**实现库存实时更新，解决多部门同时申领物品时的超卖问题，库存数据一致性达99.99%。
