1. 技术栈
   - Spring Boot + Spring Cloud + MyBatis-Plus + MySQL + Kafka + Redis +  Elasticsearch + Kafka Stream + Docker + Jenkins
2. 主要职能
   - 完成项目需求分析和技术方案设计，完成数据库设计和技术选型。
   - 使用 Spring Boot 开发用户模块、文章模块、自媒体模块等核心功能模块。
   - 使用 Spring Cloud 微服务框架实现服务注册与发现、负载均衡、熔断降级等功能。
   - 使用 Kafka 实现自媒体文章上下架的异步处理。
   - 使用 Redis 缓存热点数据，提升系统性能。
   - 使用 Elasticsearch 实现文章搜索功能，并优化搜索性能。
   - 使用 Kafka Stream 进行实时数据分析，为推荐系统提供数据支持。
   - 使用 Docker 进行项目部署，并使用 Jenkins 实现持续集成和持续交付。
